수정 완료

상태 항목 확인 방법
FIXED 레벨업 카드 후보가 현재 보유하지 않은 무기 강화를 제안하던 문제를 수정했습니다. Antonio 시작 직후 레벨업 시 Whip 강화 또는 패시브만 나오는지 확인합니다.
FIXED 무효 카드가 선택되어도 레벨과 XP 임계치가 소비되던 방어 로직을 수정했습니다. 자동 테스트 apply_card_rejects_unowned_weapon_without_leveling로 검증됩니다.

실행 전 준비

  • cargo run -p game --bin survivor로 실행합니다.
  • 타이틀 화면에서 Enter를 눌러 게임을 시작합니다.
  • W/A/S/D 또는 방향키로 이동합니다.
  • 문제가 보이면 증상, 화면, 누른 키, 대략 시간을 기록합니다.

직접 테스트 필요

상태 테스트 기대 결과
MANUAL 타이틀 → 게임 시작 → 1분 이상 생존 플레이어/적/XP/픽업/투사체가 네모가 아닌 스프라이트로 보입니다.
MANUAL 첫 레벨업 카드 3장 확인 시작 무기 Antonio 기준, 보유하지 않은 Magic Wand/Knife/Axe 등의 강화 카드가 나오지 않습니다.
MANUAL 레벨업 카드 선택 후 전투 재개 1/2/3 키 선택 뒤 게임이 멈춰 있지 않고, 선택한 강화가 반영됩니다.
MANUAL 오디오 출력 확인 assets/audio에 파일이 있으면 BGM/SFX가 재생됩니다. SFX 파일이 없으면 절차적 톤 fallback이 들립니다.

화면/HUD 가독성 확인

상태 테스트 기대 결과
MANUAL 타이틀 화면 배경과 메뉴 확인 배경 이미지가 첫 화면에 노출되고, 제목/메뉴 텍스트와 대비가 충분합니다.
MANUAL 800x600 해상도에서 InGame HUD 확인 HP/XP/Level/Time/Kills와 하단 무기/패시브 슬롯 텍스트가 서로 겹치지 않습니다.
MANUAL 무기/패시브 슬롯 이름과 레벨 확인 장비 약어 또는 이름, 레벨, 빈 슬롯 상태가 전투 중 빠르게 구분됩니다.
MANUAL 레벨업 카드 화면 텍스트 확인 카드 3장의 이름/설명/레벨 정보가 카드 영역 안에 들어가고 서로 겹치지 않습니다.
MANUAL 캐릭터 선택, 스테이지 선택, 상점 화면 확인 커서, 해금 상태, 설명 텍스트, 보유 골드가 작은 창에서도 읽을 수 있게 배치됩니다.

Settings / 업적 확인

상태 테스트 기대 결과
MANUAL 타이틀에서 O를 눌러 Settings 진입 언어, HUD 정보량, BGM 볼륨, SFX 볼륨, 해상도 항목이 표시됩니다.
MANUAL Settings에서 A/D 또는 좌우 방향키로 값 변경 언어와 HUD 정보량이 즉시 화면에 반영되고, 볼륨 값은 0~100% 범위에 머뭅니다.
MANUAL 상점 화면의 업적 요약 확인 업적 달성 수와 업적 목록 일부가 표시되고, 달성 항목과 미달성 항목이 구분됩니다.
MANUAL 첫 런 시작 후 저장 파일 확인 FirstRun 업적이 중복 없이 저장되고 보상 파워업이 1회만 적용됩니다.
